# Задание 5. Как бот справляется с каждым блоком

Проверка: `python3 src/run_sql.py src/ex05.md` из корня репозитория.

### 1. Доля закрытых ботом по блокам

**Ответ:**не размечено', 62.0

```sql
    SELECT blok, ROUND(AVG(bot_result = 'закрыл')*100,1) FROM razmetka WHERE period = 'после' AND written = 1 GROUP BY blok;
```

### 2. Решено с первого обращения по флагу

**Ответ:**не размечено', 91.6

```sql
    SELECT blok, ROUND(AVG(reopened = 0)*100,1) FROM razmetka WHERE period = 'до' AND written = 1 GROUP BY blok;
    SELECT blok, ROUND(AVG(reopened = 0)*100,1) FROM razmetka WHERE period = 'после' AND written = 1 GROUP BY blok;
    SELECT blok, ROUND(AVG(reopened = 0)*100,1) FROM razmetka WHERE period = 'после' AND written = 1 AND bot_result;
```

### 3. Решено с первого обращения с учётом возвратов

**Ответ:**не размечено', 82.2

_Какое определение ты возьмёшь для вывода и почему. Что каждое из них видит и чего не видит._

```sql
    SELECT blok, ROUND(AVG(reopened = 0 AND came_back =0)*100,1) FROM razmetka WHERE period = 'до' AND written = 1 GROUP BY blok;
    SELECT blok, ROUND(AVG(reopened = 0 AND came_back =0)*100,1) FROM razmetka WHERE period = 'после' AND written = 1 GROUP BY blok;
    SELECT blok, ROUND(AVG(reopened = 0 AND came_back =0)*100,1) FROM razmetka WHERE period = 'после' AND written = 1 GROUP BY bot_result;
```

### 4. Контроль: телефон

**Ответ:**

```sql
    SELECT period, blok, COUNT(*), ROUND(AVG(reopened = 0)*100,1) ROUND(AVG(reopened = 0 AND came_back = 0) *100,1) FROM razmetka WHERE period = 'до' AND GROUP BY blok, bot_result;
```
