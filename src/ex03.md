## Сырые данные и чистка

### 1. Сколько строк в `tickets`, сколько в ней разных номеров обращений и сколько строк в `clean`? Куда делись строки?

**Ответ:**
```sql
    SELECT COUNT(*) FROM tickets;
    SELECT COUNT(DISTINCT id) FROM tickets;
    SELECT COUNT(*) FROM clean;
```

### 2. Каналы в `tickets` и в `clean`. Что коллега исправил?

**Ответ:**

```sql
    SELECT CHANNEL, COUNT(*) FROM tickets GROUP BY CHANNEL;

    SELECT CHANNEL, COUNT(*) FROM clean GROUP BY CHANNEL;
```

### 3. Темы в `tickets` и в `clean`. Как в сырых данных записана пустая тема? Что сделал коллега? Всё ли он исправил?

**Ответ:**

```sql
    SELECT topic, COUNT(*) as cnt 
    FROM tickets 
    GROUP BY topic 
    ORDER BY cnt DESC;

    SELECT topic, COUNT(*) as cnt 
    FROM clean 
    GROUP BY topic 
    ORDER BY cnt DESC;
```

### 4. Даты: сколько строк в формате `ДД.ММ.ГГГГ` и в другом? Сколько обращений «после 1 апреля», если сравнить даты в `tickets` как есть, и сколько по `period` в `clean`? Какой период охватывает выгрузка?

**Ответ:**

```sql
    SELECT COUNT(*) FROM tickets WHERE created_at LIKE '__.__.____%';

    SELECT COUNT(*) FROM tickets WHERE created_at NOT LIKE '__.__.____%';

    SELECT COUNT(*) FROM tickets WHERE created_at >= '2025-04-01';

    SELECT COUNT(*) FROM clean WHERE period >= '2025-04-01';
```

## Пустые значения

### 5. Сколько обращений бот закрыл сам и у скольких из них нет сотрудника? Что значит пустой сотрудник? Что стало с остальными?

**Ответ:**

```sql
    SELECT COUNT(*) as total_bot_closed,
    COUNT(CASE WHEN agent_id IS NULL THEN 1 END) as bot_closed_no_agent
    FROM clean 
    WHERE status = 'closed_by_bot'; 
```

## Нумерация

### 6. Сколько номеров обращений пропущено? Сколько до 1 апреля и сколько после? Что это может значить для выводов?

**Ответ:**

```sql
    SELECT id, next_id, (next_id - id - 1) AS missing_count
    FROM (
    SELECT id, LEAD(id) OVER (ORDER BY id) AS next_id
    FROM clean
    ) t
    WHERE next_id - id > 1
    ORDER BY missing_count DESC;
```

## Бот

### 7. После 1 апреля: в каких каналах работает бот? Сколько он закрыл сам и сколько передал человеку?

**Ответ:**

```sql
    SELECT 
    channel,
    COUNT(CASE WHEN status = 'closed_by_bot' AND agent_id IS NULL THEN 1 END) AS closed_by_bot,
    COUNT(CASE WHEN agent_id IS NOT NULL THEN 1 END) AS escalated_to_human,
    
    COUNT(*) AS total_tickets
    FROM clean
    WHERE period >= '2025-04-01'
    GROUP BY channel
    ORDER BY total_tickets DESC;
```

### 8. Время первого ответа до и после апреля — отдельно для письменных каналов и для телефона. Кто отвечает первым после апреля?

**Ответ:**

```sql
    SELECT 
    CASE 
        WHEN channel IN ('чат', 'почта', 'форма' ) THEN 'Телефон'
        ELSE 'Письменные каналы'
    END AS channel_type,
    
    CASE 
        WHEN agent_id IS NULL AND (status = 'closed_by_bot' OR first_reply_by = 'bot') THEN 'Бот'
        ELSE 'Человек (Оператор)'
        END AS who_responded_first,
        COUNT(*) as tickets_count
        FROM clean
        WHERE period >= '2025-04-01'
        GROUP BY channel_type, who_responded_first;
```

## Возвраты

### 9. Сколько обращений переоткрыто и после скольких был возврат? Чем одно отличается от другого? Как это выглядит до и после апреля?

**Ответ:**

```sql
    SELECT 
        CASE WHEN period >= '2025-04-01' THEN 'После 1 апреля' ELSE 'До 1 апреля' END AS time_period,
        COUNT(CASE WHEN reopen_count > 0 THEN 1 END) AS reopened_tickets_count,
        SUM(reopen_count) AS total_reopens_volume
    FROM clean
    GROUP BY time_period;
```

## Справочник

### 10. Сколько обращений вёл каждый сотрудник и сколько — без сотрудника? Есть ли в справочнике сотрудник без обращений? Как записан номер сотрудника в `clean` и в `agents`?

**Ответ:**

```sql
    -- Tickets per employee (including those with 0 tickets)
SELECT 
    a.agent_id AS directory_agent_id,
    a.name AS agent_name,
    COUNT(c.id) AS tickets_handled
FROM agents a
LEFT JOIN clean c ON c.agent_id = a.agent_id -- assuming joining on agent_id
GROUP BY a.agent_id, a.name

UNION ALL

-- Tickets without any employee assigned
SELECT 
    'NO AGENT' AS directory_agent_id,
    'Unassigned / Bot' AS agent_name,
    COUNT(*) AS tickets_handled
FROM clean
WHERE agent_id IS NULL
ORDER BY tickets_handled DESC;


```
